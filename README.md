# AI with VD Academy: lesson code

Code and take-away files for the lessons in AI with VD Academy: https://aiwithvd.com/academy

Each lesson has its own folder under `phases/<phase>/<lesson>/`:

- `code/` has the files you run for the lesson.
- `outputs/` has the take-away files (skills and prompts) you can reuse.
